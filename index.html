The contract behind “probably”

Inserted items never test negative when the filter is intact and queried with the same encoding and hash scheme. Other items can test positive. The filter cannot enumerate its members or delete individual items safely.

Keys use exact UTF-8 bytes. A SHA-256 digest supplies two 32-bit values; the second becomes an odd step. Position i is (a + i × step) modulo the power-of-two bit count. The model estimate is (1 − exp(−kn/m))^k and is only an approximation for this double-hashing implementation.

The absent-key experiment uses a fixed synthetic probe sequence, excluding every reference-set member. Its measured rate describes those probes. Imported filters have no exact reference set, so their membership truth and absent-key experiments are unavailable.

Exported files include a checksum for accidental corruption. It is not authentication or privacy protection: anyone holding the filter can test candidate keys. The original keys are not included in the filter file.
